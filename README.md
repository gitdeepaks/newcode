# newcode

A Bun workspace monorepo with two apps:

- `apps/server`: a lightweight Hono API running on Bun
- `apps/cli`: a lightweight OpenTUI welcome screen running on Bun

## Getting Started

```bash
bun install
```

## Run

```bash
bun run dev:server
bun run dev:cli
```

## Build

```bash
bun run build:server
bun run build:cli
```
